# ユーザーガイド

## 基本ワークフロー

1. **スキャン開始**: Premiereでプロジェクトを開き、対象のシーケンスをアクティブにした状態で「スキャン開始」を押します。
   - 現時点では **アクティブなシーケンス1本** をスキャンします（複数シーケンスの一括列挙に対応するAPIが実機で確認できていないため）。複数シーケンスを扱う場合は、シーケンスを切り替えて再スキャンしてください。
2. **一覧確認**: 検出されたエフェクトが名前・カテゴリ・使用数付きの表で表示されます。検索欄やカテゴリ絞り込みで目的のエフェクトを探せます。列見出しをクリックするとソートできます。
3. **エクスポート**: 「CSV出力」「JSON出力」で、現在表示中の（検索・絞り込み後の）一覧をファイルに保存できます。
4. **整理アシスタント**:
   - 「案件名」を入力し、「チェックリスト作成」を押すと、手動整理用のチェックリストが生成されます。
   - 「クリップボードにコピー」でチェックリストをコピーできます。
   - Premiereの「エフェクト」パネルで右クリック→「新規カスタムビン」を作成し、チェックリストの順に該当エフェクトをドラッグして追加してください（**この工程はAPIで自動化できないため手作業です**）。
   - 「プロファイル保存」で、この案件の選択内容をJSONファイルとして保存できます。次回同じ案件を扱うときは「プロファイル読込」でチェックリストを復元できます。

## なぜフォルダは自動作成されないのか

Premiere Pro の UXP / CEP / QE（非公式隠しAPI）いずれにも、エフェクトパネル内へのフォルダ作成・エフェクト配置を行うAPIは、2026年7月時点の実機検証で確認されていません。Adobeが将来このAPIを公開した場合、このプラグインの後継バージョンで自動化に対応する予定です。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「開いているプロジェクトが見つかりません」 | Premiere Proでプロジェクトを開いているか確認してください |
| 「開いているシーケンスが見つかりません」 | タイムラインでシーケンスをアクティブにしてから再スキャンしてください |
| スキャンが遅い / 応答しない | クリップ数の多い大規模プロジェクトでは数十秒かかる場合があります。進捗表示が更新され続けているか確認してください |
| CSV/JSON出力ボタンが押せない | 先に「スキャン開始」でエフェクトを検出する必要があります |
