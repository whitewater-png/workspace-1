# Effect Folder Organizer

Premiere Pro プロジェクト内で使用されているエフェクトを自動検出し、一覧表示・検索・CSV/JSON出力する UXP パネルです。

## このバージョンでできること（MVP）

- 現在開いているプロジェクトのアクティブシーケンスをスキャンし、使用エフェクトを検出
- エフェクト名・カテゴリ・使用クリップ数の一覧表示、キーワード検索・カテゴリ絞り込み・列ソート
- 検出結果を CSV / JSON でエクスポート
- 「整理アシスタント」：案件名を付けてチェックリストを生成し、クリップボードにコピー。案件ごとにプロファイル(JSON)として保存・読込

## このバージョンでできないこと（重要）

2026年7月時点で実機検証された Premiere Pro UXP / CEP / QE API のいずれにも、**エフェクトパネル内へフォルダを自動作成し、エフェクトを一括配置するAPIは存在しません**。そのため本プラグインは、検出したエフェクトのチェックリストを作成するところまでを行い、Premiereの「エフェクト」パネルへの実際のフォルダ作成とドラッグ配置はユーザーの手作業となります。

同様に、汎用エフェクトの `.ffx` プリセット書き出しに対応する確認済みAPIも見つかっていないため、プリセット出力機能は未実装です（将来の技術調査項目）。

詳細は [`INSTALLATION.md`](./INSTALLATION.md) と [`USER_GUIDE.md`](./USER_GUIDE.md) を参照してください。開発の背景と技術的な意思決定は、リポジトリ内のプラン文書を参照してください。

## 動作要件

- Adobe Premiere Pro 2024.6 以降（UXP対応版）
- macOS 12.0 以上（Apple Silicon対応）

## 開発

```bash
npm install
npm test   # Jest: モック化した ppro モジュールでの純粋ロジックのユニットテスト
npm run lint
```

実際の UXP パネル動作確認は UXP Developer Tool と Premiere Pro（Developer Mode有効）が必要です。このリポジトリのクラウド開発環境では Premiere Pro を起動できないため、実機での最終確認は macOS 環境で行ってください。
